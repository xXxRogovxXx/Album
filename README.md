# Наш фотоальбom 💛

Живой фотоальбом — один `index.html` со встроенными CSS и JS. Данные берутся из `data.json`,
фото лежат в `photos/<альбом>/`.

## Как посмотреть

- **Онлайн:** опубликовано через GitHub Pages (см. Settings → Pages).
- **Локально:** проще всего через локальный сервер, тогда обновления `data.json` подхватываются сразу:
  ```bash
  python -m http.server 8000
  ```
  и открыть `http://localhost:8000`. Двойной клик по `index.html` тоже работает — есть встроенная копия данных на случай ограничений `file://`.

## Как добавить новое фото (просто!)

1. Кинь новые фото в папку `photos/` (или сразу в `photos/<альбом>/`).
   Имя файла — **любое**, хоть по-русски: программа сама переименует в латиницу.
2. Запусти **`Добавить фото.bat`** (двойной клик).
3. По каждому новому фото укажи альбом, подпись, дату и секрет → «Сохранить и далее».
   Программа сама обновит `data.json` и `index.html` (в т.ч. встроенную копию и названия вкладок).
4. Запусти **`Опубликовать в интернет.bat`** — изменения уедут на сайт, через 1–2 минуты обновится.

> Всё ещё можно править вручную: подписи и секреты лежат в `data.json`.
> После ручной правки для локального просмотра без сервера продублируй запись в `EMBEDDED_DATA` внутри `index.html`
> (или просто запусти программу — она пересоберёт встроенную копию сама).

Программе нужен установленный **Python** (уже есть на этом компьютере).

## Структура

```
index.html      # весь сайт (HTML + CSS + JS)
data.json       # список фото и подписей
photos/
  znakomstvo/
  progulki/
  chudische/
robots.txt      # запрет индексации поисковиками
.nojekyll       # отключает обработку Jekyll на GitHub Pages
```
