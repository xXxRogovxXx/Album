# Наш фотоальбom 💛

Живой фотоальбом — один `index.html` со встроенными CSS и JS. Данные берутся из `data.json`,
фото лежат в `photos/<альбом>/`.

## Как посмотреть

- **Онлайн:** опубликовано через GitHub Pages (см. Settings → Pages).
- **Локально:** проще всего через локальный сервер, тогда обновления `data.json` подхватываются сразу:
  ```bash
  python -m http.server 8000
  ```
  и открыть `http://localhost:8000`. Двойной клик по `index.html` тоже работает — есть встроенная копия данных на случай ограничений `file://`.

## Как добавить новое фото

1. Положи файл в нужную папку, например `photos/progulki/новое-фото.jpg`
   (имена файлов и папок — **латиницей**, без пробелов, это важно для хостинга).
2. Добавь запись в `data.json`:
   ```json
   {
     "id": 22,
     "folder": "progulki",
     "file": "novoe-foto.jpg",
     "title": "Подпись",
     "date": "1 января 2025",
     "secret": "Секрет по тройному клику"
   }
   ```
3. Если хочешь новый альбом — заведи папку `photos/<slug>/` и добавь красивое имя вкладки
   в `index.html` → объект `ALBUM_LABELS`.
4. Чтобы двойной клик по `index.html` (без сервера) тоже показывал новинку — продублируй запись
   в массив `EMBEDDED_DATA` в `index.html`. На хостинге это не требуется.

## Структура

```
index.html      # весь сайт (HTML + CSS + JS)
data.json       # список фото и подписей
photos/
  znakomstvo/
  progulki/
  chudische/
robots.txt      # запрет индексации поисковиками
.nojekyll       # отключает обработку Jekyll на GitHub Pages
```
